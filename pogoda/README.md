# 🌦 Погодное приложение

Погодное приложение с анимациями, прогнозами на день, неделю и месяц, геолокацией и формой обратной связи.

## 🚀 Возможности
- 🌍 **Геолокация**: Автоматическое определение вашего города.
- 📅 **Прогнозы**: На день, неделю и месяц.
- 🎨 **Темы**: Настраиваемый внешний вид (светлая, тёмная, закат, океан).
- 🎵 **Звуки погоды**: Звуки дождя, ветра, снега и грома.
- ✨ **Анимации**: Динамические анимации для разной погоды.
- 💬 **Обратная связь**: Отправка отзывов администратору.
